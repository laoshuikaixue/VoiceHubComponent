# VoiceHubComponent | 广播站排期插件

这是一个用于展示[VoiceHub](https://github.com/laoshuikaixue/VoiceHub)广播站点歌系统排期歌曲的ClassIsland插件，支持2.x版本。

使用建议：搭配滚动组件，开启宽度限制

## 功能

- 展示 VoiceHub 当天广播站排期歌曲。
- 支持按排期顺序和固定开始时间同步显示当前歌词行。
- 支持软件中途打开后按墙钟时间自动定位当前歌曲和当前歌词。
- 歌词和歌曲时长在插件端解析，不要求 VoiceHub 服务端批量生成时间轴。
- 当天歌词解析结果会缓存到本机；排期歌曲、顺序、平台 ID 或日期变化时会自动刷新缓存。
- 设置页提供“重新获取歌词”按钮，可清除本机歌词缓存并重新拉取歌词和时长。
- 歌词接口临时失败时会自动重试多次，减少偶发 API 空数据导致的“暂无歌词”。
- 网易云歌曲时长优先使用 `song/url/v1` 返回的 `time`，并和歌词长度校验；不可信时会改用备用音源估算音频时长。
- 备用网易云音源已跟随 VoiceHub 当前配置，优先使用 `https://music.rrvenn.cn/api/song`，再尝试 VKeys 和 Meting。
- 纯音乐或无歌词歌曲只要能拿到可信时长，会显示当前歌曲信息和“暂无歌词”，时间轴继续推进。
- 如果某首歌无法取得可信时长，为避免后续歌词整体错位，会从该歌曲开始停止歌词显示。
